# paint（画板与手写数字识别）

全屏画板，从桌面启动。底部工具栏：返回、四种颜色、橡皮（纸色）、笔刷粗细
（默认 16px）、清空、识别开关（眼睛）。

打开识别后，抬笔 0.7 秒没有新笔画就识别一次画布上的所有笔画（从上次清空
开始），顶部滑入结果卡片：结果、置信度、前三名和模型实际看到的 28×28 输入，
点卡片收起。写下一个数字前先清空。每次识别也会把 28×28 输入和结果打到串口。

## 识别

识别代码在公共库 `app/digit`（bench 也用它比较两种推理实现），见那里的
README。打开 `CONFIG_TFLITEMICRO` 时识别跑在 TFLite Micro 上，串口行末尾会
写 `on TFLite Micro`；TFLM 初始化失败或没打开时用手写的 C 推理。
