# touch（触摸测试）

从全部应用页启动，深色风格和 bench 一致。

- 分隔线以下随便画：手指位置有一个圆圈，移动时留下轨迹，抬起后 0.3 秒开始
  淡出。每一笔换一种颜色
- 顶部实时显示坐标、每秒收到的触摸报点数、当前触点数
- `CALIBRATION CHECK`：屏幕四角和中心依次出现十字靶，点一下记录偏差，最后
  给出平均偏差、最大偏差、平均偏移方向和每个靶的偏差，同时打到串口
  （`touch: ...`），再点一下关闭
- 返回按钮在左上角，标题栏不画轨迹，画画时不会误触

## 报点率

样本在 LVGL 触摸输入设备的读回调里取：touch 把 NuttX 驱动的读回调包了一层。
LVGL 每个输入周期会把驱动里攒下的样本都读完（`continue_reading`），所以每个
控制器报上来的点都会被计数、画进轨迹，而不是每个输入周期只看到一个点。

GT9XX 驱动每次只报一个点（`TSIOC_GETMAXPOINTS` 返回 1），所以触点数只有 0 和
1，轨迹也只有一条。多点触控要改驱动。
