# touch（触摸测试）

从全部应用页启动，深色风格和 bench 一致。

- 分隔线以下随便画：每根手指一种颜色，手指位置有一个圆圈，移动时留下轨迹，
  抬起后 0.3 秒开始淡出
- 顶部实时显示第一根手指的坐标、每秒收到的触摸报点数、当前手指数
- `CALIBRATION CHECK`：屏幕四角和中心依次出现十字靶，点一下记录偏差，最后
  给出平均偏差、最大偏差、平均偏移方向和每个靶的偏差，同时打到串口
  （`touch: ...`），再点一下关闭
- 返回按钮在左上角，标题栏不画轨迹，画画时不会误触

## 多点和报点率

LVGL 的 NuttX 触摸驱动只把一个点交给 LVGL（多点要打开手势识别），所以 touch
不用它的读回调，而是自己读触摸屏：LVGL 把触摸屏的文件描述符放在驱动数据的
第一个成员（`lv_nuttx_touchscreen.c` 注释里写明了），touch 换上自己的读回调，
每次读一个样本，里面每根手指的按下 / 移动 / 抬起都画出来，第一根手指交给
LVGL 用来点按钮。还有样本时设 `continue_reading`，LVGL 会接着读，快速点按的
按下和抬起不会被合并掉。

多点需要 nuttx 的 GT9XX 驱动报告所有触点（`CONFIG_INPUT_GT9XX_NPOINTS`，默认
5）。原来的驱动只报一个点，那时这里也只有一条轨迹；提示文字里的手指数来自
`TSIOC_GETMAXPOINTS`。
